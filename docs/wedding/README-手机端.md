# 手机端使用注意事项

面向小董、小赵在手机 / iPad 上使用「小董和小赵的备婚计划」。

---

## 1. 怎么打开

两部设备请打开**同一个链接**：

| 方式 | 地址 | 适用情况 |
| --- | --- | --- |
| **云端链接（推荐）** | https://yuanyuan-D.github.io/D-Z/wedding/ | 任意网络；**电脑可关机** |
| 本地调试 | http://电脑局域网IP:5180 | 仅同 Wi‑Fi，且电脑开着 `server.py` |

浏览器右上角点「分享」，可扫码或复制链接。建议用 **Safari / Chrome**；微信内置浏览器异常时选「在浏览器中打开」。

---

## 2. 电脑不用一直开着

正式使用走 **Supabase + GitHub Pages**（与 family-menu 同思路）：

- 网页在 GitHub Pages，数据在云端
- 家里电脑休眠 / 关机不影响手机使用
- 首次需在电脑上按 [DEPLOY.md](./DEPLOY.md) 执行一次 `supabase/schema.sql`

若顶部显示「待建云端表」，说明云端表还没建好，按横幅提示完成即可。

---

## 3. 双方同步怎么用

- **「云端已同步」**：已连上云端，两边改动能互相看见
- **「双方已同步」**：连的是家里电脑上的本地同步服务（调试用）
- **「离线本地」**：只存在本机，对方看不到；检查网络后刷新
- 切回 App / 刷新页面会立刻拉取最新数据
- 减重打卡请各自选择 **小董** 或 **小赵** 再记录

---

## 4. 保存相关

- 勾选、采购、改文案、打卡后会自动保存并同步
- 右上角「保存」可手动确认
- 有未确认更改时，关闭页面可能弹出离开提示

---

## 5. 编辑与增补

- **改** / **删** / **＋添加**：任务、采购、预算、须知等均可编辑
- 改完会自动同步到对方设备

---

## 6. 建议习惯

1. 收藏云端链接，不要用过期的 localtunnel 地址  
2. 两人始终用同一个链接  
3. 重要改动后看一眼顶部是否仍为「云端已同步」
